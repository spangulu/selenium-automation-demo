# Selenium Java Automation Demo

A small **Java + Selenium WebDriver + JUnit 5** browser automation example by **Sarath Panguluri**, Test Automation Engineer.

## Demo

`ExampleDomainTest` opens `https://example.com/` in headless Chrome, checks its page title, and closes the browser.

## Requirements

- Java 17+
- Maven
- Chrome/Chromium installed (Selenium Manager can handle driver setup)

## Example command

```bash
mvn test
```

This is a **portfolio demonstration**, not a production test suite. The test was **not executed** as part of preparing this repository.
